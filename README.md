# Advocacia Edvaldo Rodrigues

Site institucional da Advocacia Edvaldo Rodrigues, localizada em Praia Grande/SP.

## 🛠️ Tecnologias Utilizadas

- **Vite** - Build tool e servidor de desenvolvimento.
- **TypeScript** - Linguagem de programação.
- **React** - Biblioteca para construção de interfaces.
- **Tailwind CSS** - Framework de estilização.
- **shadcn/ui** - Componentes de UI modernos.
- **Framer Motion** - Animações premium.

## 🚀 Como Executar o Projeto

1. Clone o repositório.
2. Navegue até o diretório do projeto.
3. Instale as dependências:
   ```sh
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```sh
   npm run dev
   ```

## 📝 Sobre o Projeto

Este site foi desenvolvido para fornecer uma presença digital profissional para o Dr. Edvaldo Rodrigues, destacando suas áreas de atuação e facilitando o contato via WhatsApp.
